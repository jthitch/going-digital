# Logo Directory

Upload your Going Digital logo here.

## Logo Specifications

### Main Logo
- **logo.png** - Main logo file
- **Recommended dimensions**: 200px width × 40px height (or proportional)
- **Format**: PNG with transparent background (recommended) or JPG
- **Max file size**: 100KB for fast loading

### Alternative Formats
- **logo.svg** - Vector logo (best for scalability)
- **logo@2x.png** - Retina/high-DPI version (double the dimensions)

## How to Use

1. **Upload your logo** to this folder (`static/img/logo/`)
2. **Name it `logo.png`** (or `logo.svg` for vector)
3. **The logo will automatically appear in the header!**

## Header Behavior

- Logo appears on the left side of the header
- If logo image is not found, "Going Digital" text will be displayed instead
- Logo is clickable and links to the homepage
- Logo height is set to 40px (width scales proportionally)

## Logo Styling

The logo will be:
- Displayed in the header navigation bar
- Clickable (links to homepage)
- Responsive (scales on mobile devices)
- Maximum width of 200px to prevent overflow

## Tips

- Use PNG with transparency for best results
- SVG format is ideal for crisp display on all screen sizes
- Keep file size small for fast page loading
- Test on both light and dark backgrounds if your header color changes
