# Favicon Directory

Upload your favicon files here. The site will automatically use them.

## Supported Favicon Formats

### Primary Favicon (Recommended)
- **favicon.png** or **favicon.ico** - Main favicon file
- Recommended size: 32x32px or 16x16px (ICO format)
- For PNG: 32x32px, 64x64px, or 128x128px

### Optional Additional Icons
- **apple-touch-icon.png** - For iOS home screen icon (180x180px)
- **favicon-16x16.png** - 16x16 PNG variant
- **favicon-32x32.png** - 32x32 PNG variant

## How to Use

1. **Upload your favicon file** to this folder (`static/img/favicon/`)
2. **Name it `favicon.png` or `favicon.ico`**
3. **Refresh your browser** - the favicon will appear automatically!

## Quick Setup

**For ICO format (best compatibility):**
- Name: `favicon.ico`
- Size: 16x16 or 32x32 pixels
- Multiple sizes in one file is supported

**For PNG format:**
- Name: `favicon.png`
- Size: 32x32, 64x64, or 128x128 pixels

## Testing

After uploading:
1. Clear your browser cache (Ctrl+F5 or Cmd+Shift+R)
2. Or use incognito/private mode to see the new favicon immediately

The favicon will appear in:
- Browser tabs
- Bookmarks
- Browser history
- Mobile home screen (if apple-touch-icon.png is provided)
