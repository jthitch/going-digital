# Create a course

A **course** is the product definition (e.g. “Get Off Auto”). Workshops are the dated sessions of that course at specific venues.

## Who can do this

- Typically **super users / administrators**. Franchisees may have limited course access depending on permissions.

## What “done” looks like

1. Course is **Active**.
2. Skill level and category are set.
3. Description and SEO fields are filled.
4. Card image (and optional gallery media) look good on the course list.
5. The course appears on **[Browse photography courses]({{ urls.public_courses }})**.

## Prerequisites

- Skill level and category already exist (or create them under Courses first).
- Optional: images uploaded under **[Images]({{ urls.image_changelist }})**.

## Steps

### 1. Open Courses

Go to **[Courses]({{ urls.course_changelist }})**.

### 2. Add a course

Click **[Add course]({{ urls.course_add }})**.

Complete the main fields:

| Field | Guidance |
|-------|----------|
| **Course name** | Public title. |
| **Slug** | Used in the course’s web address (auto-fills from the name; keep it short and unique). |
| **Skill level** | Beginner / intermediate / etc. Drives homepage journey tiles and filters. |
| **Category** | Landscape, portrait, editing, etc. |
| **Active** | Must be on for the public site. |
| **Description** fields | Student-facing copy; keep it clear and scannable. |
| **Region** | Usually only for one-to-one style courses (see info icon on the field). |

### 3. SEO fields

Fill meta title, description, and keywords when available. These appear in search results and social previews.

### 4. List card image

Set the card/list image and focal point so the course looks strong on:

- [Photography courses list]({{ urls.public_courses }})
- Homepage journey sections

### 5. Media gallery (optional)

Use the images/videos inline on the course form for the detail page gallery.

### 6. Save and preview

1. Save the course.
2. Open **View on site** if shown, or find the course on **[Photography courses]({{ urls.public_courses }})**.
3. Confirm title, copy, and pricing placeholders (prices come from workshops).

## Common mistakes

- Course **Active** but no bookable workshops — it may look empty or low priority on the list.
- Weak or missing card image — hurts conversion on the list page.
- Slug changes after publishing — breaks old links; avoid renaming live slugs.
- Putting venue-specific dates on the course — dates belong on **workshops**.
